# Bayesian Regularized Kernel Machine

Consider the task to predict a target variable $y_t$ based on the information summarized in a vector of regressors $x_t$. The first step one can take is to conduct a decomposition via the identity equation $y_t = E(y_t|x_t) + \epsilon_t$, where $E(y_t|x_t)$ is the expectation of $y_t$ conditional on $x_t$ and $\epsilon_t \equiv y_t - E(y_t|x_t)$ is the residual. It is straightforward to show that the correlation between $E(y_t|x_t)$ and $\epsilon_t$ is 0 and that $E(y_t|x_t)$ minimizes the mean squared error between $y_t$ and any function $f(x_t)$. Hence, the task is concretized to be inferring the function $E(y_t|x_t)$ from historical data.

The linear regression model assumes $E(y_t|x_t)$ as a linear function of $x_t$ and has been a time-tested workhorse model widely used in practice. However, such a linearity assumption is clearly too restrictive and could be prone to failure in complicated real situations. On the other hand, modern machine learning methods such as kernel machine has powerful capacity to allow nonlinearity but is prone to overfitting without effective regularization. If a linear regression model is "good enough" for a task at hand, why bother going for the more complicated nonlinear models? The challenge is that, in reality, one never knows beforehand if a linear model is adequate or not. Can we have a model that is able to detect the boundary? Ideally, the model "knows" to use the linear model when nonlinearity is unimportant in the data while adding nonlinear part when the linear model is "sensed" to be inadequate. 

The Bayesian regularized kernel machine developed in my research is an attempt to address the aforementioned challenge, where Bayesian shrinkage priors are employed to achieve effective regularization. In a nutshell, a general form of the Bayesian regularized kernel machine is to model $E(y_t|x_t)$ as $x_t' \beta + g(x_t)$, where $\beta$ is a vector of linear coefficients of $x_t$ and $g(x_t)\equiv E(y_t|x_t) - x_t' \beta$ follows a Gaussian process with a kernel matrix $K$. By the universal approximation theory (Hornik et al 1989), $g(x_t)$ is able to capture any nonlinear relationship between $x_t$ and $y_t$. The difficulty is how to "kill" $g(x_t)$ when the relation between $x_t$ and $y_t$ is close to be linear and the linear part $x_t' \beta$ in $E(y_t|x_t)$ is sufficient. The novelty of the Bayesian regularized kernel machine is that a shrinkage prior is applied to the kernel matrix $K$ such that $K$ can be 0 and thus $g(x_t) = 0$, suppressing the nonlinear part of $E(y_t|x_t)$. Estimation of the Bayesian regularized kernel machine can be conducted efficiently via the Markove chain Monte Carlo method. 

In my experiments on simulated and real-world economic data, the Bayesian regularized kernel machine shows encouraging results. In the simulated exercise, the Bayesian regularized kernel machine is able to perform on par with the linear regression model when the true data is from a linear data generating process and outperforms the linear regression model by a large margin when nonlinearity is added to the data generating process. Compared with the alternative of directly modeling $E(y_t|x_t)$ as a Gaussian process, the Bayesian regularized kernel machine performs on par in the nonlinear data generating process case while outperforms when the data generating process is linear. An exercise to predict the aggregate non-interest income of U.S. banks by economic variables also finds the benefit of the Bayesian regularized kernel machine relative to the alternatives.
